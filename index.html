Guía rápida

Instalación en 4 pasos

Necesitas OBS Studio, Streamer.bot, Twitch conectado en Streamer.bot y WebSocket Server activo.

Abre el panel

Entra al panel de configuración y ajusta diseño, colores, metas, sonidos, redes y clima local.

Importa la acción

Copia el código de importación y agrégalo en Streamer.bot desde Actions.

Activa WebSocket

En Streamer.bot usa host 127.0.0.1 y puerto 8080, o los datos que configures.

Pégalo en OBS

Copia el enlace generado y úsalo como Browser Source / Fuente de navegador.

Streamer.bot

Código de importación

Este bloque importa la acción que permite enviar eventos, metas, estado del stream y datos del canal al widget.

Cómo importarlo

1️⃣Abre Streamer.bot.
2️⃣Ve a Actions y pulsa Import.
3️⃣Usa Import from Clipboard o guarda el código como archivo .sbaction.
4️⃣Confirma que la acción Hipe Widget quede habilitada.
5️⃣Agrega el trigger Twitch → General → Stream Update para actualizar la categoría en vivo.

Cómo funcionan las metas

Subs y follows usan saltos por rangos. Bits puede funcionar por stream o de forma mensual.

🎯 Subs

Usa el conteo real de Twitch y calcula la siguiente meta automáticamente. Si las subs bajan bastante, la meta se reajusta.

100 a 99950

❤️ Follows

Funciona igual que subs: crea metas cercanas, sube al alcanzarlas y puede reajustar si el conteo baja.

💎 Bits

En modo stream se reinicia al terminar directo. En mensual guarda acumulado y protege los bits reales.

Solución de problemas

Si algo no funciona

La mayoría de problemas vienen de Streamer.bot cerrado, WebSocket apagado, enlace viejo, ubicación/clima sin configurar o URLs de imágenes incorrectas.

❌ SIN SEÑAL

Abre Streamer.bot y activa General → WebSocket Server. Verifica host 127.0.0.1 y puerto 8080.

🔇 No suenan eventos

Revisa sonido global, sonidos por evento, volumen y que exista assets/goal.mp3 para celebración.

🖼️ No se ven imágenes

Usa enlaces públicos directos terminados en .png, .jpg, .gif, .webp o .mp4.

🎮 Categoría no cambia

Agrega el trigger Twitch → General → Stream Update a la acción Hipe Widget.

🌦️ No aparece el clima

Activa “Mostrar clima local” en el panel, detecta ubicación o escribe ciudad, latitud y longitud manualmente. Después vuelve a copiar el enlace y actualízalo en OBS.

¿Necesito saber programar?

No. Se configura desde el panel. Solo importas la acción en Streamer.bot y pegas el enlace en OBS.

¿Tengo que copiar el enlace otra vez si cambio algo?

Sí. El enlace contiene la configuración. Si cambias colores, metas, redes, eventos o clima local, vuelve a copiarlo y actualízalo en OBS.

¿Puedo usar mis propias imágenes?

Sí. Puedes usar URLs públicas directas o subir tus archivos a la carpeta assets del sitio.

¿Streamer.bot debe estar abierto?

Sí. Si Streamer.bot está cerrado, el widget no recibe eventos en tiempo real.

¿El clima necesita Streamer.bot?

No. El clima se configura desde el panel y se consulta directamente desde el widget usando la ubicación configurada. Streamer.bot sigue siendo necesario para eventos, metas, estado del directo y categoría.

¿Cada cuánto se actualiza el clima?

El clima se carga al abrir el widget y se actualiza automáticamente cada 10 minutos.
